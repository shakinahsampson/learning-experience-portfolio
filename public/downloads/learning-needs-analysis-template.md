# Learning Needs Analysis Template

| Section | Prompts |
|---|---|
| **Business problem** | What is happening? How do we know? What is the cost of inaction? |
| **Desired performance** | What should people do differently? In what context? |
| **Root cause** | Knowledge, skill, motivation, environment, or tools? Which gaps can training address? |
| **Audience** | Roles, prior knowledge, tools, constraints, accessibility needs |
| **Constraints** | Time, budget, technology, approvals |
| **Success measures** | Level 1–4 indicators (see evaluation plan template) |
| **Stakeholders** | Sponsor, SME, manager, learner reps |
| **Recommendation** | Learning solution and non-learning solutions |
