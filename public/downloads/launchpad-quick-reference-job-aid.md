# LAUNCHPAD Quick Reference — Work Management Platform (Simulated)

Fictional platform ("FlowBoard") used for a portfolio demonstration. Not a real product.

## Update a project status
1. Open the project → **Status** tab.
2. Choose **On track**, **At risk**, or **Off track**.
3. Add a one-sentence summary: what changed, what is next.
4. Select **Post update**.

## Identify a blocker
- Open the task → **Flag blocker**.
- Describe: what is blocked, since when, what is needed.
- Tag the person who can unblock.

## Assign ownership
- One owner per task. Use **Collaborators** for helpers.
- Set a due date at the same time.

## Escalate a risk
| Situation | Action |
|---|---|
| Blocker unresolved > 2 days | Message owner's manager with the blocker link |
| Delivery date at risk | Change status to At risk and notify project lead |
| Cross-team dependency | Post in #flowboard-help and tag dependency owner |

## When something doesn't work
1. Refresh and retry.
2. Check the support FAQ.
3. Post in #flowboard-help with a screenshot.
4. Email the platform support desk if urgent.
