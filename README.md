# From Knowledge to Action

Independent instructional design portfolio prototype by Shakinah Sampson.

A 12-screen, responsive browser-based onboarding experience demonstrating performance-based learning design, workplace decisions, explanatory feedback, documentation practice, and an assessment summary. Built with HTML, CSS, and JavaScript; no subscription or external libraries required.

## Run locally
Open `index.html` in a modern browser.

## Publish on GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.

## Portfolio disclosure
Meridian Consumer Brands and all company procedures, policies, cases, and data are fictional. This independent demonstration is not an employer-commissioned product or an Articulate Storyline export. All rules and evaluation criteria are illustrative and require SME validation before real-world use.

## Design note
The course implements the 12-screen design concept. Scoring uses first-attempt selections across five decision checks; the case-note exercise checks required-field completion only and does not verify factual correctness. No LMS reporting or user-data collection is implemented.
